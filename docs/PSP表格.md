## 预估依据（写清楚才不会被认为是拍脑袋）

| 环节 | 预估依据 |
|---|---|
| 接口分析 150 min | 需要阅读 B 站接口文档、逆向 wbi 签名算法、试通搜索与弹幕两个接口 |
| 具体编码 520 min | 11 个业务模块 + 1 个 CLI 编排，按平均 45 min/模块估算 |
| 测试 180 min | 34 个用例，含手工构造 protobuf 二进制与替身 Session，平均 5 min/用例 |
| 可视化 含在编码内 | 词云中文字体调试、6 张 matplotlib 图、pyecharts 大屏 |
| 博客 200 min | 三个一级标题、含图表说明与心得，约 6000 字 |
